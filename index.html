个人 Lovart API 设置

          
每个人填写自己的 Access Key + Secret Key；网站按 Lovart 官方 HMAC 签名方式直连 OpenAPI。

        

        
      

      

        

          Lovart AK / SK
          按照 Lovart OpenAPI 的官方鉴权方式：Access Key 用来标识调用者，Secret Key 只在当前浏览器本地用于 HMAC-SHA256 签名。Secret Key 本身不会作为请求字段发送给 Lovart。
        

        
        
        
        

          
          
        

        
        
本版仍是纯前端。如果 Lovart 的 OpenAPI 没有允许浏览器 CORS，自定义鉴权请求会被浏览器拦截；这种情况与 AK/SK 是否正确无关。
