# AI Skill Canvas v0.7

本版基于 v0.5 的 Lovart AK/SK + HMAC OpenAPI 版，增加以下功能：

## 1. 底部输入区改为可折叠紧凑栏
- 默认收起，只保留当前 Skill、生成数量、查看提示词、展开按钮、生成按钮。
- 展开后输入区内部滚动，不再大面积遮挡无限画布。
- 生成完成后自动收起。

## 2. 输出尺寸改为“画面比例”
Skill 创建/编辑页从像素分辨率改为：
- 16:9
- 20:9
- 9:16
- 9:20
- 1:1
- 4:3
- 3:4

旧版 Skill 如果保存了 1920x1080 / 2048x2048 等分辨率，会自动映射为最接近的画面比例。

## 3. 画布直接接收本地图片
- Windows 文件夹中的 PNG/JPG/WebP 等图片可直接拖进无限画布。
- 支持 Ctrl+V 粘贴剪贴板图片/截图到画布。
- 图片会成为独立的 Canvas Image 节点，并保存在浏览器 IndexedDB 项目里。

### 从画布填入 Skill 图片端口
每个图片端口增加“从画布选图”：
1. 点击图片端口的“从画布选图”。
2. 再点击画布里的本地图片或 Lovart 生成结果。
3. 图片自动填入该端口。

如果画布上已经选中一张图片，再点“从画布选图”，会直接使用当前选中的图片。

## 4. 生图数量
底部紧凑栏支持选择一次生成：
- 1 张
- 2 张
- 3 张
- 4 张

真实 Lovart 模式下会为每个方案创建独立 Thread，让多个方案互不阻塞；参考图只上传一次并复用 CDN URL。

## 5. Lovart 对话继续编辑
生成结果卡片增加“继续编辑”：
- 有原 Lovart Thread 时：复用 `thread_id` 继续同一对话，Lovart 保留上一轮上下文。
- 本地/无 Thread 图片：自动把当前图片作为 attachment，创建新的编辑对话。
- 进入继续编辑模式后，Skill 初始输入端口会暂时隐藏，只需要填写新的修改要求。

## 6. Lovart 鉴权
仍使用：
- Access Key
- Secret Key
- HMAC-SHA256
- Base URL: `https://lgw.lovart.ai`

Secret Key 只保存在当前浏览器本地，并用于本地签名。

## v1.0 Bugfix
- Skill 选择改为最简单流程：点击“选择 Skill” -> 点击某个 Skill -> 立即选中并关闭弹窗。
- Skills JSON 导入同时兼容纯 Skill 数组和包含 `skills` 的项目 JSON；导入后自动选中第一个新导入 Skill。
- 本地图片节点不再使用背景图模拟，改为真实 `<img>` 元素。
- 拖入图片在画布 100% 缩放时按原始像素尺寸显示，并保留原始宽高信息。
- 修复旧版 CSS `height:auto!important` 导致图片节点高度为 0、图片不可见的问题。


## v1.1 更新
- 生成结果卡片新增 **下载图片** 按钮。
- 优先以浏览器下载方式保存生成图；若遇到跨域限制，会自动打开图片链接作为兜底。


## v1.2 更新
- 拖入/粘贴到画布的图片也新增 **下载图片** 按钮。
- 所有图片节点（本地图与生成结果）均支持 **放大 / 缩小**。
- 新增 **Ctrl + 滚轮** 缩放当前选中的图片。
- 画布平移操作改为 **鼠标中键拖动**。


## v1.3 更新
- 参考 Lovart 的操作逻辑：**左键点选图片后出现四角缩放手柄**。
- 支持直接拖拽四个角对图片进行缩放，保持比例。
- 选中图片后，会在图片上方显示更大的悬浮操作条。
- 图片卡片底部按钮也整体放大，便于点击。


## v1.4 更新
- 图片选中后的顶部工具条和四角缩放手柄改为固定屏幕尺寸，不再随图片或画布缩放变小。
- 删除图片下方操作按钮；顶部工具条移除“放大/缩小”。
- 四角拖拽手柄显著放大。
- 普通滚轮改为画布上下移动；Ctrl + 滚轮只缩放整个画布。
- 鼠标中键可从图片上直接开始拖动画布。


## v1.5 更新
- **画面比例从 Skill 编辑器移除**。
- 用户选择 Skill 后，在右侧运行面板选择 `16:9 / 20:9 / 9:16 / 9:20`。
- 画面比例属于每次运行参数，不再属于 Skill 模板配置。


## v1.6 更新
- 编辑/续编模式重新布局，顶部控件拆成更宽松的多行，不再拥挤。
- 点击画布中的图片或生成结果，会自动成为右侧对话区的当前编辑图片。
- 右侧新增当前编辑图片预览；切换画布图片时自动切换预览。
- Skill 图片端口处于“从画布选图”状态时，仍优先填入端口，不触发编辑模式。


## v1.7 Canvas 操作逻辑重构
- 左键单击只负责选择，不再自动进入 AI 编辑；双击或 Tab 才进入编辑。
- Shift+单击多选；空白区域左键拖框选择。
- 多选浮动工具条：左/顶对齐、横向分布、下载、删除。
- 参考图改为专用选择模式：可连续选择，显示 1/2/3 顺序，完成/取消。
- Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y 撤销重做。
- 右键菜单：编辑、作为参考、下载、锁定、层级、删除等。
- F 适应当前选择；Space+左键或鼠标中键拖动画布。


## v1.8 更新
- Skill 运行模式下，点击画布图片只做选中，不再在右侧显示“当前选中图片 / 编辑这张图”。
- 只有显式进入图片编辑/续编模式时，右侧才显示当前编辑图片。
- 所有文本类 Skill 输入端口改为整行宽度。
- 多行描述默认提高到约 6 行可视高度，单行文本输入也加宽加高。
